Privacy policy

rclone-nuc — personal Google Drive sync client

This policy describes how rclone-nuc handles Google user data. The application is a private tool operated by a single individual on their own hardware. It has exactly one user: the owner of the Google Account that authorised it.

1. What Google data is accessed

The application requests the Google Drive scope https://www.googleapis.com/auth/drive, which allows it to read and write files in the owner's Google Drive. In practice it accesses:

  • File and folder names, metadata and contents in the owner's My Drive
  • Google Docs, Sheets and Slides, which are exported to Office formats for local use
  • Shared Drive content only if the owner has added it to their Drive

The application does not request access to Gmail, Calendar, Contacts, Photos or any other Google service.

2. How the data is used

Data is used for one purpose only: maintaining a synchronised copy of the owner's own Google Drive on the owner's own server, so that the files remain available if the Google Account or the cloud service becomes unavailable. No data is analysed, profiled, mined, or used for advertising.

3. Where data is stored

Files are stored on a server located in the owner's home, on storage devices owned and controlled by the owner. An encrypted backup of that server is kept on a local USB disk in the same household. Data is not stored on any third-party hosting service.

4. Sharing and disclosure

Google user data is never sold, rented, shared, transferred or disclosed to any third party. No third-party analytics, trackers, advertising networks or sub-processors are used. The application does not transfer Google user data to anyone, including Google itself beyond the API calls required for synchronisation.

5. Retention and deletion

Data is retained only for as long as the owner keeps it on their server. Deleting a file from Google Drive removes the corresponding local copy at the next sync; deleting a local file removes the corresponding Drive file (which remains recoverable in the Google Drive trash for its normal retention period). Revoking the application's access does not automatically delete local copies; the owner deletes them manually if desired.

6. Revoking access

The owner can revoke the application's access at any time at myaccount.google.com/permissions. Once revoked, the application can no longer read or write any Google data.

7. Security

OAuth credentials are stored with owner-only file permissions on the server, and all communication with Google uses HTTPS. The server is not exposed to the public internet.

8. Changes to this policy

If this policy changes, the updated version will be published on this page with a new date.

9. Contact

Questions about this policy or about Google user data handled by this application: open an issue.
