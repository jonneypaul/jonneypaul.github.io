rclone-nuc

A private, self-hosted Google Drive sync client.

rclone-nuc is a personal automation running on its owner's own home server. It uses the Google Drive API to keep a copy of the owner's own Google Drive in sync with storage on that server. It is not distributed, has no other users, and is not offered as a public service.

What it does

  • Reads files, folders and Google Docs from the owner's Google Drive.
  • Writes changes made on the server back to the owner's Google Drive.
  • Exports Google Docs, Sheets and Slides to Office formats for local editing.
